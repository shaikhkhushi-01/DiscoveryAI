# LLM-extracted research-gap dataset: safe import

The Mendeley Data V2 dataset is an **external weak-label resource**, not the
DiscoveryAI adjudicated gold benchmark.

## Import

From the repository root:

```bash
python scripts/evaluation/import_weak_label_research_gap_dataset.py \
  --input "/path/to/gaps_v2.csv" \
  --output "artifacts/weak_labels/research_gap_dataset_v2.json"
```

The importer validates the required columns, unique paper IDs, dates, boolean
own-work flag and the train/validation/test split. It writes a provenance-
preserving JSON artifact with a SHA-256 hash of the original CSV.

## Important scientific boundary

The source labels (Limitation, Research Gap, Importance) were generated by
language models from title and abstract. They are not expert-validated or
adjudicated and do not contain full-text evidence, document IDs, or chunk IDs.
The importer therefore marks every row as non-adjudicated and emits
`evaluation_eligibility.status=not_gold_benchmark_compatible`.

Do not:
- pass this artifact to the adjudicated DiscoveryAI benchmark runner;
- rename or promote these labels to gold/adjudicated annotations;
- report its agreement as expert accuracy or evidence-grounded retrieval quality;
- use Importance or Limitation as input features when predicting Research Gap
  without explicitly studying target leakage;
- claim chronological generalization: the provided splits are random, not time-based.

Permitted initial use is descriptive analysis and carefully labelled weak-label
exploration. The artifact retains generator-model provenance because the source
uses more than one generation model and style may be a confounder.

Source: [Mendeley Data, Research Gap Discovery Dataset, V2]
(https://data.mendeley.com/datasets/px9xd7tw8n/2), DOI: 10.17632/px9xd7tw8n.2.

The existing Phase 4 five-system and six-ablation benchmark protocol remains
blocked until there is a compatible corpus-linked benchmark with traceable
evidence and valid gold annotations. This import does not unblock that protocol.
