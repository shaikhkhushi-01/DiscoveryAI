# Day 39 — Extraction Evaluation Protocol

## Required sample
Create a manually annotated corpus of representative scientific papers before reporting extraction metrics.

## Suggested metrics
- Entity precision / recall / F1 by field
- Exact-match and normalized-match rates for metadata
- Limitation/future-work classification accuracy
- JSON schema validity rate
- Unsupported extraction rate

## Error categories
- missed entity
- false entity
- wrong normalization
- wrong section attribution
- wrong limitation category
- wrong future-work category
- hallucinated claim

No metric is reported until a real gold set is populated.
